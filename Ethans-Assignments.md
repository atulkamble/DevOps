# DevOps Training – Session-Wise Assignments

Total: 24 Assignments + 1 Final Project

| Session | Assignment                          | Practical Tasks                                                                                                                                                           |
| ------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1       | DevOps Fundamentals                 | Draw DevOps lifecycle, compare DevOps vs Traditional IT, list DevOps tools and their uses.                                                                                |
| 2       | Git Basics & GitHub                 | Install Git, configure username/email, create repository, commit files, push and pull from GitHub.                                                                        |
| 3       | Git Branching & Rollback            | Create branches, merge, rebase, cherry-pick, resolve conflicts, practice stash, reset, revert and restore.                                                                |
| 4       | Docker Fundamentals                 | Install Docker, pull Nginx image, create and run container, expose port 8080, inspect container and view logs.                                                            |
| 5       | Docker Images, Networking & Storage | Create Dockerfile, build and push image to Docker Hub, create custom network, configure volume and bind mount.                                                            |
| 6       | Docker Compose                      | Create Docker Compose YAML for WordPress and MySQL, configure networking and persistent storage, start and stop services.                                                 |
| 7       | Kubernetes Fundamentals             | Draw Kubernetes architecture, identify control plane and worker node components, explain Pods, Services and Deployments.                                                  |
| 8       | Kubernetes Cluster, Pods & Services | Install Kubernetes tools, configure Minikube or kubeadm cluster, create Pod YAML, deploy Pod and expose using Service.                                                    |
| 9       | Kubernetes Deployments & Ingress    | Create Deployment with 3 replicas, scale application, perform rolling update and rollback, configure Ingress routing.                                                     |
| 10      | AWS ECR                             | Create private ECR repository, build Docker image, authenticate using AWS CLI, tag and push image to ECR.                                                                 |
| 11      | AWS EKS                             | Create EKS cluster and node group, configure kubectl, deploy application using ECR image and verify Pods.                                                                 |
| 12      | Kubernetes Scheduling               | Create namespaces, assign node labels, configure nodeSelector, apply taints and tolerations, verify Pod scheduling.                                                       |
| 13      | Ansible Fundamentals                | Install Ansible, configure inventory, establish SSH connectivity, execute ping and ad-hoc commands.                                                                       |
| 14      | Ansible Playbooks                   | Create YAML playbook to install Nginx, start service, deploy HTML page and verify application.                                                                            |
| 15      | Ansible Roles & Variables           | Create Ansible role with tasks, handlers, templates and variables; execute reusable playbook.                                                                             |
| 16      | Terraform Fundamentals              | Install Terraform, configure AWS provider credentials, create basic Terraform configuration and verify installation.                                                      |
| 17      | Terraform Providers & Workflow      | Write Terraform code to provision AWS EC2 instance, execute init, plan, apply and destroy.                                                                                |
| 18      | Terraform Variables & State         | Implement variables and outputs, configure remote state using S3 with locking, organize reusable Terraform configuration.                                                 |
| 19      | Maven Build Automation              | Install Java and Maven, create Java project, configure pom.xml, execute compile, test and package.                                                                        |
| 20      | SonarQube Code Quality              | Install SonarQube, create project, configure scanner, analyze source code and review quality reports.                                                                     |
| 21      | Prometheus & Grafana                | Install Prometheus, configure Node Exporter, add scrape target, install Grafana and create monitoring dashboard.                                                          |
| 22      | Jenkins Fundamentals                | Install Jenkins, configure administrator account, explore dashboard, create and execute first Jenkins job.                                                                |
| 23      | Jenkins Freestyle Job               | Create freestyle job, connect GitHub repository, configure build steps and webhook, verify automated build.                                                               |
| 24      | Jenkins CI/CD Pipeline              | Create Jenkinsfile, configure credentials, implement checkout, build, test and deployment stages, execute pipeline.                                                       |
| Final   | End-to-End DevOps Project           | Provision infrastructure using Terraform, configure with Ansible, build Docker image, push to GitHub Container Registry, deploy to Kubernetes and automate using Jenkins. |

## Assignment Submission Requirements

Students must submit the following for each practical assignment:

1. GitHub repository link containing code and configuration files.
2. Screenshots of successful execution.
3. Commands used during implementation.
4. Short README.md with execution steps.
5. Final output or verification results.

Final Project Deliverable: Working application with Terraform, Ansible, Docker, Kubernetes and Jenkins CI/CD integration.
